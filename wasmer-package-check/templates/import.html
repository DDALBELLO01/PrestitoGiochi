Importa Database

Informazioni

L'importazione permette di ripristinare i dati da un file Excel precedentemente esportato.

  • Seleziona un file Excel (.xlsx o .xls) esportato in precedenza
  • Scegli se sostituire tutti i dati esistenti o aggiungere solo nuovi elementi
  • Il processo importerà: Giochi, Soci e Prestiti
Seleziona un file .xlsx o .xls esportato dal sistema
⚠️ ATTENZIONE: Se selezionato, tutti i dati attuali verranno eliminati e sostituiti con quelli del file di backup. Se non selezionato, verranno aggiunti solo i nuovi elementi.
Importante: Si consiglia di esportare un backup prima di procedere con l'importazione.

Domande Frequenti
Quando usare l'importazione?

- Ripristino da backup dopo un problema
- Trasferimento dati tra computer
- Sincronizzazione con un altro database

Cosa succede ai dati esistenti?

- Se "Elimina dati esistenti" è selezionato: tutti i dati attuali vengono rimossi
- Se non selezionato: vengono aggiunti solo elementi con ID non esistenti

Formato del file

File Excel (.xlsx o .xls) con 3 fogli obbligatori: Giochi, Soci e Prestiti.
Il file deve avere la stessa struttura di quello esportato dal sistema.

Come ottenere un file di esempio?

Usa "Esporta in Excel" dal menu Database per scaricare un file con la struttura corretta.
